# KIBOiT-plus
～次の転職を、今より良いものへ～
<br>
<br>
### 【概要】
客先常駐のないIT求人のみを掲載する転職サイトです。
<br>
<br>
### 【サイト立ち上げの理由】
IT業界の求人を探していると、客先常駐を前提とした求人が数多く見つかります。
その中で、「自社で働きたい」「客先常駐ではない環境で働きたい」と考える方にとって、希望する求人を探しにくい状況があると感じ、本サイトを立ち上げました。
開発・インフラ・テスト・ITサポートなど、特定の職種に限定することなく、IT業界のさまざまな仕事の中から、自分に合った求人を見つけられる場所を目指します。
<br>
<br>
### 【キャッチフレーズ！！】
**「また客先常駐か。。。」**<br>
<br>
そう思ったこと、ありませんか？<br>
<br>
だったら最初から、客先常駐のない求人だけで探しませんか？
<br>
客先常駐なしのIT求人のみ掲載。
開発・インフラ・テスト・サポートなど、あなたに合ったITの仕事を、客先常駐なしで。
